# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it by emailing [hello@onfranciis.dev](hello@onfranciis.dev).  
Do **not** create a public issue for security-related matters.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Security Best Practices

- Keep your dependencies up to date.
- Never share sensitive credentials in code or public repositories.
- Review pull requests for potential security issues.

## Responsible Disclosure

We appreciate responsible disclosure of vulnerabilities. We will respond as quickly as possible to your report and keep you informed of our progress.
